# 💳 Smart Expense Tracker App

A simple and powerful **Expense Tracker Web App** built using **Python & Streamlit**.  
This app helps users track their income and expenses easily with a clean dashboard.

---

## 🚀 Live Demo
👉 https://smart-expenses-tracker-app-kjkwsvmj5wmlpfuxk7a3qk.streamlit.app/

---

## 📌 Features

- ➕ Add income and expenses  
- 🗂 Categorize transactions (Food, Travel, Shopping, etc.)  
- 📝 Add notes for each transaction  
- 📊 Dashboard with income, expense, and savings  
- 🔍 Search and filter transactions  
- ❌ Delete selected transactions  
- 📥 Download data as CSV  
- 👤 Personal user-based data (each user has separate data)

---

## 🛠 Tech Stack

- **Python**
- **Streamlit**
- **Pandas**
- **Matplotlib**
